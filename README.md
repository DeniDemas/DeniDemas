### 2. 📱 Тестирование мобильного приложения BestScore QaBattle (Личный кейс)
* **Объект:** Мобильное приложение для учета игрового счета в боулинге.
* **Окружение:** Смартфон Xiaomi 14, эмулятор LDPlayer (Android 9.0 / API 28).
* **Локализованные критические баги и уязвимости:**
  * **Vulnerability (Critical):** Полное отсутствие санитаризации ввода. Приложение позволяет сохранять SQL-инъекции и XSS-скрипты в качестве имен лиг (`' OR '1'='1`, `<script>alert(1)</script>`).
  * **Logic Bug (Major):** Некорректный расчет среднего балла (`League Average`). Приложение грубо усекает дробную часть (`300 + 149 / 2 = 224` вместо `224.5`).
  * **Data Validation (Major):** Отсутствие валидации взаимосвязанных полей в настройках (система позволяет сохранить значение `BorderNormalGame` выше, чем `BorderGoodGame`).
  * **UX/UI:** Нарушение архитектуры навигации (модули открываются в блокирующих модальных диалогах вопреки спецификации), отсутствие Empty State при пустом списке.
* 🔗 **[Посмотреть чек-листы и тест-кейсы](https://docs.google.com/spreadsheets/d/1SN7hA0c0-wlrmqRUjPmvN5WqOjHBAePkdWwTqLTwBu0/edit?usp=sharing)**

### 3. 🍽 Тестирование веб-приложения Dinner (Личный кейс)
